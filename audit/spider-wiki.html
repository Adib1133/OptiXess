Marvels Spider‐Man 2

Jump to bottom
Michał Lewandowski edited this page May 6, 2026 · 6 revisions

Last Tested Version

0.9

Filename

dxgi.dll

OS

Win 11 24H2

GPU

RX 9070XT

Upscaler Inputs

DLSS, FSR3.1, XeSS

Settings

  • Dxgi = false for Intel/AMD as Spoofing is unnecessary

    • DLSS-FG is unlocked already without Dxgi spoofing

    • DLSS is locked without spoofing, but FSR/XeSS upscaling inputs work just fine, use them instead.

FG-Settings

  • FSR 3.1 FG → FSR-FG/XeFG

  • DLSSG via SL → FSR-FG/XeFG

Known Issues

  • For AMD/Intel cards, using Ray Tracing while Spoofing crashes the game at startup

    • Either avoid using RT when spoofing or disable spoofing by setting Dxgi=false in OptiScaler.ini and check FG-Settings above.

    • Since 0.9, Opti is now automatically disabling Dxgi spoofing

Notes

  • When using DLSSG via SL make sure you actually enabled DLSSG in the game options as otherwise hudless will be missing

Reported By

TheRazerMD
