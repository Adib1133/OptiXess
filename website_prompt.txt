=========================
OVERVIEW
=========================

OptiXess is a Windows desktop GUI tool that automates installation and management of OptiScaler for Intel Arc GPU owners. OptiScaler is an open-source project that enables XeSS upscaling and XeSS Frame Generation in games that do not natively support them. This Gui sits on top of it — it handles downloading OptiScaler releases, deploying the correct proxy DLL into game folders, generating OptiScaler.ini configs, snapshotting original files, and recovering from failures.

The website should be a single-page landing page with smooth scroll sections. No backend required. Everything is static HTML/CSS/JS.

SECTION 8: FAQ
---
Section title: "Frequently Asked Questions"
Accordion-style expandable Q&A:

Q: Does this work without an Intel Arc GPU?
A: Yes. Manual mode works on any GPU. Automatic recipes and Arc-specific features require an Arc GPU.

Q: Will this work on my game that's not in the reviewed list?
A: Yes — switch to Manual mode, choose your proxy filename and upscaler input, and install. Read the OptiScaler wiki for game-specific notes first.

Q: Does OptiXess touch a running game process?
A: No. It only writes files to the game folder while the game is closed. It never injects into a running process.

Q: What is Force Inject?
A: Force Inject bypasses validation errors (unmanaged proxy conflicts, recipe hook mismatches, etc.) and uses your exact chosen settings. A confirmation dialog is shown first.

Q: What happens if the game crashes after installation?
A: Use Launch & Monitor to detect startup crashes automatically — OptiXess will roll back to original files. Or use Revert manually at any time.

Q: Does my OptiScaler.ini get overwritten on updates?
A: No. OptiXess generates a fresh INI and then merges in your existing edits. Your manual tweaks are preserved.

Q: Is the download compressed with BCJ2?
A: Yes, official OptiScaler .7z releases use BCJ2 compression. OptiXess uses Windows built-in bsdtar to extract them, which fully supports BCJ2.
