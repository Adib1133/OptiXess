Overview

What is OptiXess?

OptiXess is a Windows desktop configurator that automates per-game OptiScaler installations — specifically designed for Intel Arc GPU owners who want XeSS upscaling and XeSS Frame Generation without manual file management.

It downloads OptiScaler releases, deploys the correct proxy DLL under the exact filename your game needs, generates and preserves your OptiScaler.ini, snapshots original game files, and recovers from failures automatically.

Game-aware

Reads local game files, detects upscalers.

Arc-native

Detects XMX hardware, disables unnecessary spoofing.

Safe recovery

Full file snapshots, hash-verified restore.

Force inject

Override validation errors when you know what you're doing.

Features

Everything you need. Nothing you don't.

Intel Arc Detection

Detects A-series (Alchemist) and B-series (Battlemage) Arc GPUs. Confirms XMX AI matrix acceleration and displays your hardware in the header badge. Click it to open a full System Info panel.

Smart Game Detection

Scans local DLL names to identify native XeSS SR/FG, DLSS, and FSR. Cross-references the official OptiScaler wiki by game title. Native XeSS is never overwritten.

Reviewed Automatic Recipes

Verified installation plans for Spider-Man 2, Spider-Man Remastered, Miles Morales, Midnight Suns, and DCS World. Recipes choose the right proxy, constrain inputs, and enforce location requirements automatically.

Proxy Filename — Fixed

OptiScaler.dll is deployed under the exact filename you select — winmm.dll, version.dll, dxgi.dll, and more. No more silently injecting as dxgi when you chose something else.

INI Preservation

On every install or update, your manual OptiScaler.ini edits are merged into the new config. Your custom tweaks survive re-injections.

Force Inject

When Install is blocked by a validation error or mod conflict, Force Inject overrides all checks. Shows a confirmation dialog; overridden errors appear as warnings in the log.

Workflow

Get XeSS running in 4 steps

01

Download a Release

Open the Downloads tab, refresh the release list, and click Download & Install. OptiScaler is extracted using Windows bsdtar — BCJ2 compression supported.

02

Add Your Game

Point OptiXess to your game's .exe in the Library tab. It scans local files and checks the OptiScaler wiki for documented settings automatically.

03

Configure & Install

Choose XeSS upscaling, XeSS Frame Generation, proxy filename, and quality preset. Click Install / Update. Your original files are snapshotted before anything is written.

04

Launch & Verify

Launch through OptiXess for crash monitoring, or launch normally. Open the in-game OptiScaler overlay (Insert key) to confirm XeSS/XeFG is active.

Release management

Full release management, built in

Reference

Which proxy DLL should I use?

dxgi.dllDefault. Most DX11/DX12 games.
winmm.dllWhen dxgi conflicts with another mod.
version.dllAlternative for some Unreal Engine games.
nvngx.dllGames that load DLSS via nvngx directly.
d3d12.dllSome DX12 games (may conflict — test carefully).
dbghelp.dllFallback for older engines.
wininet.dllRare alternative.
winhttp.dllRare alternative.
